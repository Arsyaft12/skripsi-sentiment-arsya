# 🌟 Next.js Modern Developer Portfolio Template Pro

A premium, state-of-the-art developer portfolio template built with **Next.js 16 App Router**, **TypeScript**, **Tailwind CSS v4**, **Framer Motion**, and an optional **Supabase + Live GitHub Integration**.

---

## ✨ Features

- 🎧 **Interactive Audio Widget & Focus Mode**: Custom built-in HTML5 Audio player with equalizer animation and sound controls.
- ⚡ **Centralized 5-Minute Customization**: Edit just `src/config/portfolio.config.ts` to customize all names, bio, social links, and SEO metadata.
- 🌙 **Dark / Light Glassmorphism Mode**: Fluid theme switching with subtle ambient lighting glow and background gradients.
- 📱 **Fully Responsive**: Optimized for ultra-wide monitors, tablets, and smartphones.
- 💼 **Modular Sections**:
  - Hero with dynamic ticker role rotator and social links dock.
  - Profile, Core Competencies, Career Timeline & Education.
  - Interactive Project Showcase & Live Health Checker.
  - Verified Credentials & Certificate modal viewer.
  - Interactive Public Guestbook & Direct Inquiry Form.
- 🚀 **Zero-Config Deployment**: 1-click deploy to Vercel or Netlify.

---

## 🚀 Quick Setup

```bash
# Clone the repository
git clone -b template https://github.com/Arsyaft12/skripsi-sentiment-arsya.git my-portfolio
cd my-portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.
